# NYC Housing Affordability Analysis

## Project Overview

This project looks at how housing affordability has changed across New York City.

The main question I want to answer is:

**How has housing affordability changed across NYC, and which boroughs or neighborhoods are becoming the least affordable relative to income?**

## Goals

- Compare housing costs across NYC
- Compare housing costs to income
- Look at changes over time
- Find differences between boroughs and neighborhoods
- Create clear visualizations of the results

## Tools

- Python
- SQL
- Pandas
- Data visualization
